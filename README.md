# Дневник тренировок

Приложение-дневник для iPhone: адаптация (4 недели) и 4 этапа основной программы, ввод веса, подходов и повторов, тоннаж, таймер отдыха, план и прогресс.

Открыть: https://wm7019918.github.io/dnevnik/ → в Safari «Поделиться» → «На экран „Домой“».

Записи хранятся только на телефоне (в приложении). Резервная копия — «Настройки» → «Сохранить резервную копию».
